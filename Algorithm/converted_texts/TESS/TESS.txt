I. INTRODUCTION
对于空间信用分配，反馈对齐（FA）和直接反馈对齐（DFA）等方法使用随机矩阵来传播误差
信号或直接将误差投影到单个层，从而减少层依赖性；
在脉冲神经网络（SNN）的时序信用分配中，基于三因子学习规则的方法利用资格痕迹来以
生物合理的方式保留时序信息。例如，e-prop 通过资格痕迹处理显式循环连接SNN中的时序信用分
配，并依赖反向传播（BP）或前向对齐（DFA）进行空间信用分配。另一些方法将资格痕迹与DRTP结
合，实现了时空局部性，但仅适用于浅层网络（2–3层），且因内存开销随突触数量增长（O(Ln2)）
而难以扩展到深层架构。
相比之下，受STDP启发的时序局部学习规则（S-TLLR）在性能上可与BPTT媲美，同时内存消
耗降低5–50倍，运算量减少1.3–6.6倍。其内存需求仅随神经元数量线性增长（O(Ln)），且与时间步
数无关。然而，S-TLLR仍依赖基于反向传播的误差传递来实现空间信用分配。
为克服现有方法的局限并实现高效的设备端学习，我们提出了TESS——一种新颖、可扩展的
时空局部学习规则，用于训练脉冲神经网络（SNN）。与先前存在扩展性问题或依赖层间全局误差
传播的方法不同，TESS从根本上以时空局部的方式解决了内存和计算开销的瓶颈。
具体而言，TESS通过灵感源于S-TLLR的资格痕迹解决时序信用分配问题，其内存复杂度与神
经元数量成线性关系。对于空间信用分配，TESS采用一种机制，通过使用局部生成的学习信号（灵
感源于固定基向量方法）调制资格痕迹，来同步每层内的神经元活动。这种完全局部的方法消除了
层间反向传播的需求，从而能够扩展到更深架构和更大数据集，同时保持与时间步数无关的内存复
杂度（O(Ln)）和计算复杂度（O(LCn)）。

III. 方法：PROPOSED METHOD - A SCALABLE FULLY LOCAL LEARNING RULE
本节提出一种时间高效且可扩展的完全局部脉冲神经网络学习规则（Temporal Efficient and Scal-
able Spiking Learning, TESS）。该方法在保持替代梯度训练稳定性的同时，消除了对时间反向传播
和全局误差信号的依赖。
A. 方法总体思想
TESS 的核心思想是将基于BPTT 的梯度更新过程分解为两个局部可计算的组成部分：
• 表征历史时间依赖关系的资格迹；
• 表征当前神经元可塑性的局部学习信号。
在该框架下，权重更新可在每一个时间步独立完成，无需访问未来时刻或其他层的误差信息。
B. 资格迹的构造
对于第l 层突触权重，定义基于前突触脉冲活动的资格迹：

IV. TESS: STDP与局部学习信号机制
TESS（Temporally and Spatially Local Learning Rule）通过结合生物启发的STDP机制和完全局
部化的学习信号生成，实现了高效、低复杂度的脉冲神经网络训练。
1. STDP机制实现
TESS使用两种资格迹来模拟STDP的时序依赖特性：
1.1 因果资格迹（LTP部分）: 前脉冲先于后脉冲，对应STDP中的长时程增强（LTP）窗口：
q(l)[t] = λpreq(l)[t −1] + o(l−1)[t]

• Ψ(·)：替代梯度函数（实验中用三角函数）
• αpre = 1：LTP强度控制因子

2. 局部学习信号生成:Learning Signal Generation (LSG) 空间信用分配
TESS使用完全局部化的学习信号生成机制，避免层间误差传播：
2.1 学习信号公式:

• B(l)：固定二进制投影矩阵（维度C × n(l)）

2.2 投影矩阵设计: B(l)的设计特点：
1) 固定二进制：元素值∈{+1, −1}，不参与训练
2) 方波函数列：每列对应特定空间频率的方波模式
3) 准正交性：不同类别的方波模式近似正交
4) 硬件友好：XOR/XNOR操作即可实现投影
2.3 神经同步机制: 投影矩阵通过方波模式实现：
• 同一类别的神经元分配相同相位方波，促进同步发放
• 不同类别的神经元分配不同相位方波，实现异步发放
• 通过投影误差检测任务相关模式

V. LSG过程和投影矩阵B的看法
文章中没有更详细的关于这两个部分的论述。对于这个文章可以感受到其这一段论述主要是在
这一段：
The LSG process begins by projecting the output spikes of each layer, o(l)[t], into a C-dimensional
task subspace using a projection matrix B(l). This projection captures the relevant task information for
the layer. Next, a function f(·) is applied to the projected vector to compute its alignment with the target
vector y∗. The choice of f(·) depends on the task: for classification problems, f(·) is the softmax function,
while for regression tasks, it is simply the identity function. The difference between the projected vector
and the target, f(B(l)o(l)[t]) −y∗, serves as the error signal. This error signal is then projected back to
the layer using the transpose of the projection matrix, B(l)⊤, resulting in the modulatory learning signal,
m(l)[t], which is given by:
m(l)[t] = B(l)⊤ f(B(l)o(l)[t]) −y∗
.
(23)
The design of the projection matrix B(l) is a critical component of the LSG process. In TESS, B(l)
is defined as a fixed binary matrix, with each column corresponding to a square wave function. This
design offers several advantages. The square wave functions help synchronize the activity of neurons
within the same layer by assigning distinct spatial frequencies to different classes, ensuring that the
task-related information is distributed effectively across the layer. Furthermore, the columns of B(l) are
quasi-orthogonal, minimizing interference between the projections of different classes. The simplicity of
square wave functions also makes them highly hardware-efficient, which is particularly advantageous for
implementation in resource-constrained environments.

VII. ELIGIBILITY TRACE与LSG的设计逻辑及公式分析
本节从公式来源、计算原因以及物理/生物/算法意义三个层面，对TESS 中的Eligibility Trace
与Local Learning Signal Generation (LSG) 机制进行详细分析。重点说明作者为何采用这样的递推
形式、这些变量分别编码了什么信息，以及它们如何共同实现时空上的局部训练。
A. TESS 的核心目标：实现时空局部训练
TESS 的设计目标是在脉冲神经网络（Spiking Neural Networks, SNNs）中同时解决以下两个信
用分配问题：
• Temporal credit assignment：当前时刻的损失如何归因到过去若干时刻的神经活动；
• Spatial credit assignment：当前层的任务误差信息如何分配给该层内部各个神经元和突触。
传统的BPTT 需要沿时间与层两个方向传播误差，这导致训练必须保存完整的历史状态，并进
行全局反向传播，从而带来较高的内存与计算开销。TESS 的核心思想是：将原本依赖全局反向传
播的学习过程拆解为两个局部机制：
1) 使用Eligibility Trace 在局部保存时间历史的压缩表示，从而替代时间维度上的反向传播；
2) 使用LSG 在每一层本地生成任务相关的学习信号，从而替代层间误差反传。
因此，TESS 通过局部状态变量和局部学习信号的组合，实现了完全局部的权重更新。
B. Eligibility Trace 的基本思想
在三因子学习规则（three-factor learning rule）中，突触更新通常写为
∆Wij[t] ∝mi[t] eij[t],
(34)
其中：
• eij[t] 为eligibility trace，用于记录该突触在最近一段时间内是否“有资格”被更新；
• mi[t] 为调制信号（modulatory signal），用于决定该更新应朝哪个方向进行。
从生物启发角度看，eligibility trace 对应于突触对历史pre/post 神经活动的短时记忆；从算法
角度看，它相当于用一个递推变量在线压缩历史信息，从而避免显式保存完整时间序列。

C. q(l)[t] 的定义、计算原因与意义
TESS 定义pre-synaptic trace 为
q(l)[t] = λpreq(l)[t −1] + o(l−1)[t].
(35)
将其递推展开可得
q(l)[t] = o(l−1)[t] + λpreo(l−1)[t −1] + λ2
preo(l−1)[t −2] + · · ·
(36)
因此，q(l)[t] 的本质是对前一层脉冲活动的指数加权累积，即一个一阶低通滤波器。它体现了
以下含义：
• 计算原因：当前神经元的膜电位往往不是由单个时刻的输入决定，而是由一段时间内输入脉冲
累积形成。因此，仅使用当前时刻的o(l−1)[t] 无法反映输入历史对当前输出的贡献；
• 物理意义：q(l)[t] 表示该层输入端在最近一段时间内的活跃程度，越近的脉冲影响越大；
• 生物意义：它可视为前突触活动的局部痕迹（pre-synaptic trace），对应突触短时可塑性中的
“前神经元最近是否频繁发放”；
• 算法意义：它用一个递推变量在线编码输入历史，从而替代BPTT 中显式保存整个时间序列的
做法。
参数λpre ∈[0, 1) 决定了该记忆的长度：
• 当λpre 较小时，只保留非常短期的输入历史；
• 当λpre 较大时，可保留更长时间范围内的输入影响。
因此，q(l)[t] 体现的是前神经元活动的衰减记忆，其作用是将时间维度上的输入历史压缩为一
个当前可用的局部状态。
D. h(l)[t] 的定义、计算原因与意义
TESS 定义post-synaptic trace 为
h(l)[t] = λposth(l)[t −1] + Ψ(u(l)[t −1]),
(37)
其中Ψ(·) 为辅助激活函数，用于度量膜电位对发放的敏感程度。
展开递推可得
h(l)[t] = Ψ(u(l)[t −1]) + λpostΨ(u(l)[t −2]) + λ2
postΨ(u(l)[t −3]) + · · ·
(38)
因此，h(l)[t] 是对post-synaptic 状态历史的指数衰减累积，其含义如下：
• 计算原因：若只使用当前时刻的spike 输出，则只能获得0/1 的离散信息，无法反映神经元
“接近阈值但尚未发放”的状态。而后者在训练中同样重要；
• 物理意义：h(l)[t] 表示该层神经元近期膜电位敏感性的积累，即后神经元在最近一段时间内是
否多次接近阈值；
• 生物意义：它可以看作post-synaptic trace，用于刻画后神经元的可塑性历史；
• 算法意义：它为非因果项提供后神经元历史信息，使局部更新不仅考虑pre-before-post，还考
虑post-before-pre 的时序关系。

这里使用Ψ(u(l)[t −1]) 而不是o(l)[t −1] 的关键原因在于：膜电位携带比二值spike 更丰富的
连续信息，更适合作为surrogate gradient 的近似，从而使学习过程更加平滑。
参数λpost 的意义与λpre 类似，用于控制后神经元状态记忆的时间跨度。
因此，h(l)[t] 体现的是后神经元状态的衰减记忆，其作用是捕捉post 端的短时动态历史。
E. 因果与非因果Eligibility Trace 的设计逻辑
基于上述两个局部历史变量，TESS 构造了两类eligibility trace。
1) 因果项:
e(l)
pre[t] = αpreΨ(u(l)[t]) ⊗q(l)[t]
(39)
该式的设计逻辑如下：
• Ψ(u(l)[t]) 表示当前后神经元对突触输入的敏感性；
• q(l)[t] 表示前神经元近期活动的历史累积；
• 外积⊗用于生成与权重矩阵同维度的突触更新候选项。
因此，e(l)
pre[t] 表示：若某个pre neuron 在最近一段时间内持续活跃，同时当前某个post neuron
正接近发放阈值，则连接这两个神经元的突触应被视为具有较高的更新资格。
从STDP 视角看，这对应于一种pre-before-post 的因果配对。从算法角度看，这一项是在局
部近似
∂u(l)[t]
∂W (l)
中与前向输入历史相关的部分。
2) 非因果项:
e(l)
post[t] = αposth(l)[t] ⊗o(l−1)[t]
(40)
其设计逻辑为：
• h(l)[t] 表示后神经元在过去一段时间内的敏感度历史；
• o(l−1)[t] 表示当前时刻前神经元的spike；
• 二者外积构成另一类时序配对。
这表明：若post neuron 在前一段时间里已经多次接近阈值，而当前pre neuron 才发生spike，
则这种时序关系同样可能对应有意义的突触更新。
从生物学上，这对应于STDP 中的non-causal term；从算法上，这为模型提供了对更复杂时
序关系的补偿能力。
参数αpre 和αpost 分别控制这两类eligibility trace 的强度。尤其是αpost 可取正、负或零，表示
非因果项可以被正向利用、反向利用或直接关闭。
F. 为什么Eligibility Trace 能实现时间局部性
传统BPTT 的难点在于：为了计算某一时刻的梯度，必须保存过去所有时刻的状态，并在未来
获得损失后沿时间反传。TESS 则用q[t] 和h[t] 将“过去发生过什么”压缩到当前局部状态变量
中。

=== PAGE 14 ===
14
因此，Eligibility Trace 的关键作用并不是精确恢复完整梯度，而是用局部递推方式构造一个对
历史敏感的突触资格量。这样一来，每个时刻的更新都只依赖于：
• 当前时刻的膜电位与spike；
• 上一时刻保存下来的trace；
• 当前时刻的局部学习信号。
这意味着时间维度上的学习完全可以在线进行，而不需要跨时间反向传播。因此，Eligibility
Trace 机制实现了temporal locality。
G. LSG 的定义与设计逻辑
在解决时间信用分配之后，还需要解决空间信用分配。TESS 中的局部学习信号定义为
m(l)[t] = B(l)⊤ f(B(l)o(l)[t]) −y∗
,
(41)
其中：
• o(l)[t] 为当前层输出脉冲；
• B(l) 为固定投影矩阵；
• f(·) 为任务相关读出函数，分类时一般取softmax；
• y∗为目标标签。
该式的计算分为两步：
a) (1) 投影到任务子空间:
z(l)[t] = B(l)o(l)[t]
(42)
这一步将当前层的神经元活动映射到一个低维任务空间中。其目的在于：即使不是输出层，中间层
也可以直接获得与任务相关的读出表示，而不必依赖最终输出层的误差反传。
b) (2) 误差计算与回投影:
δ(l)[t] = f(z(l)[t]) −y∗
(43)
m(l)[t] = B(l)⊤δ(l)[t]
(44)
其中，δ(l)[t] 表示在任务空间中的局部误差信号，而B(l)⊤则将该误差信号重新映射回当前层
神经元空间，从而为每个神经元产生一个本地学习信号。
H. B(l) 矩阵的设计原因与意义
文中指出，B(l) 被设计为一个固定的二值矩阵，其每一列对应一个square wave function。这
一设计具有以下几方面意义：
• 算法意义：B(l) 充当固定读出头与固定反馈头，使得每一层都可在本地生成与任务相关的误差
信号，而不必依赖跨层梯度传播；
• 表示意义：不同类别对应不同的空间频率模式，有助于将任务信息分散到整层神经元活动中；
• 结构意义：这些列向量近似正交（quasi-orthogonal），从而减小不同类别之间的相互干扰；

=== PAGE 15 ===
15
• 硬件意义：二值方波矩阵易于存储和实现，矩阵乘法成本较低，更适合边缘设备和神经形态硬
件部署。
因此，B(l) 并不是一个需要训练的参数矩阵，而是一个预先设计好的固定结构矩阵，其本质作
用是：在局部层级建立从神经元活动到任务误差的桥梁。
I. 为什么LSG 能实现空间局部性
在传统BP/BPTT 中，某一隐藏层的学习信号来自后续层逐层反传的误差，因此隐藏层无法独
立完成更新。而在TESS 中，LSG 让每一层都具备了本地产生学习信号的能力。
具体而言，当前层只需知道：
• 自己的输出o(l)[t]；
• 固定投影矩阵B(l)；
• 监督信号y∗。
便可独立构造m(l)[t]。这个过程不依赖上层梯度，也不依赖未来层的状态。因此，LSG 实现了
spatial locality。

K. 参数设置对复现的启示
从复现角度看，以下参数具有明确的功能含义：
• λpre：控制pre-trace 的记忆长度；
• λpost：控制post-trace 的记忆长度；
• αpre：控制因果项权重；
• αpost：控制非因果项是否启用以及以何种符号参与更新；
• Ψ(·)：决定膜电位敏感性如何被近似；
• B(l)：决定每层如何将活动映射到任务相关空间；

这些参数并非孤立存在，而是共同决定了TESS 在局部训练中对时间历史、任务误差以及神经

调试，而不仅仅是机械地套用数值。
L. TESS 内存与计算复杂度分析
在TESS 算法中，内存和计算复杂度可以用大O 表示法描述：
a) 符号说明:
• L：网络层数（number of layers）；
• n：每层平均神经元数（average number of neurons per layer）；
• C：任务目标维度（number of classes for classification 或输出维度）。
b) 内存复杂度: TESS 内存主要用于存储每层神经元的eligibility traces，例如q(l)[t] 和
h(l)[t]。由于TESS 不存储时间步的全部历史，而只保留当前时间步的trace，因此：
Memory ∝L · n
即内存复杂度为
O(Ln)
随层数或每层神经元数线性增加，并且与时间步数T 无关。
c) 计算复杂度: TESS 的主要计算量来源于生成局部学习信号：
m(l)[t] = B(l)⊤ f(B(l)o(l)[t]) −y∗
其中o(l)[t] 的长度为n，投影矩阵B(l) 尺寸为C × n，因此单层计算量约为C · n。总计算量随层数
累加：
Computation ∝L · C · n
即计算复杂度为
O(LCn)
相比传统BPTT (O(TLn2)) 大幅降低，尤其是任务输出维度C ≪n 时。

M. 本节总结
TESS 的设计可以概括为：使用q[t] 和h[t] 将时间历史压缩为局部trace，用B(l) 与LSG 将任
务误差信息转换为每层可独立生成的局部学习信号，再将二者组合为三因子学习规则形式的权重更
新。其本质不是对BPTT 的逐项精确复制，而是在生物启发、硬件可实现性与算法有效性之间寻找
平衡，从而实现低复杂度、可扩展的局部训练机制。
VIII. 实验评估：EXPERIMENTAL EVALUATION
• CIFAR-10：包含10 类自然图像的帧基视觉分类数据集，用于评估TESS 在标准静态视觉任务
上的性能；
• CIFAR-100：包含100 类自然图像的数据集，用于检验方法在类别数显著增加时的可扩展性；
• CIFAR10-DVS：由CIFAR-10 转换得到的事件驱动版本，用于评估TESS 在异步脉冲输入条件
下的表现；
• DVS Gesture：基于动态视觉传感器采集的手势识别数据集，用于验证TESS 在真实事件流任
务中的适用性。
训练过程中采用以下策略：
• 使用离散时间LIF 神经元模型进行前向传播；
• 在每一个时间步基于TESS 规则进行权重更新；
• 不进行时间维度上的反向传播或状态缓存；
• 使用替代梯度函数稳定局部学习信号；
• 所有层均采用完全局部的学习规则，不引入全局误差信号。
对于帧基数据集，输入在时间维度上进行重复或编码，以适配脉冲神经网络的时序处理方式；
对于事件基数据集，则直接使用事件流作为网络输入。
A. 训练与测试结果
实验结果表明，TESS 在多个数据集上的分类性能与基于BPTT 的替代梯度方法接近。
在CIFAR-10 与CIFAR-100 数据集上，TESS 能够在不使用时间反向传播的前提下，实现与
BPTT 方法相当的测试精度。尽管在部分设置下测试精度略低于BPTT，但性能差距保持在较小范
围内。
在事件驱动数据集（如CIFAR10-DVS 与DVS Gesture）上，TESS 同样能够实现稳定训练，并
获得具有竞争力的识别准确率，验证了该方法在真实时间异步输入场景中的有效性。
